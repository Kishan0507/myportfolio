# Fedora Terminal Portfolio 👨‍💻

A unique, interactive, full-stack developer portfolio styled like a Fedora Linux terminal. It features a fully functioning dynamic React frontend and a Django REST API backend to manage content.

## ✨ Features

* **Interactive Terminal UI:** A retro, glassmorphism-inspired Fedora terminal interface that makes exploring the portfolio fun and unique.
* **Dynamic Content Management:** Add and update achievements, contributions, and profile details via a built-in Django Admin dashboard.
* **Real-time GitHub Stats:** Fetches and displays live GitHub repository statistics.
* **Visitor Tracking:** Keep track of how many people have visited your portfolio.
* **Responsive Design:** Works flawlessly across desktops, tablets, and mobile devices.
* **Production Ready:** Pre-configured for seamless deployment on platforms like Render (with WhiteNoise for static file serving and environment variable support).

## 🛠️ Technology Stack

**Frontend:**
* React (via Vite)
* React Router DOM (for seamless navigation)
* Vanilla CSS / Glassmorphism UI
* Lucide React (for crisp iconography)

**Backend:**
* Python 3.x
* Django & Django REST Framework
* SQLite (easily scalable to PostgreSQL)
* WhiteNoise (Static file serving)
